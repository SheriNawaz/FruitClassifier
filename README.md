# AI-coursework

This is a coursework project for the Programming and Mathematics with AI module

Dataset:
https://www.kaggle.com/datasets/karimabdulnabi/fruit-classification10-class/data

All libraries used in this coursework are listed in the 'requirements.txt' file.
To install all libraries, run the command:
pip install -r requirements.py

Open project in a Jupyter Notebook
